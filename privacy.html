MackroBytes privacy policy

MackroBytes is a private inventory tracker used by one person, its owner, for their own resale shop. It has no other users and sign-ups are closed.

Gmail access

  • MackroBytes asks for read-only Gmail access (gmail.readonly) to the owner's own mailbox.
  • It only searches for Depop sale-confirmation emails (from sold@alerts.depop.com). From those it reads the item title, price, payout and buyer username, and it uses them to mark the owner's own items as sold.
  • It never sends, deletes, labels or changes email. Email contents aren't stored, apart from those sale fields, and they're never shared, sold or used for ads.
  • Google user data is handled under the Google API Services User Data Policy, including the Limited Use requirements.

Where data lives

Item data is stored in the owner's private Supabase database. The Gmail sign-in token is kept in a private table that only the server can read.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
